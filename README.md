# AI-native SDLC · Навигатор погружения

Интерактивный сайт-конспект по **всей** ветке **AI Native SDLC** (пространство SSD, `wiki.office.msk.mtt`) и по **учебному проекту `ai-sdlc-training`** (личный кабинет МТС Exolve). Основной фокус — переход **системного аналитика в AI-native аналитика**.

Сайт статический: чистый HTML + CSS + JS без сборки, зависимостей и сетевых запросов. Открывается двойным щелчком по `index.html` (работает и по `file://`).

Документация: https://wiki.office.msk.mtt/display/SSD/AI+Native+SDLC

## Как открыть

1. Открой `ai-sdlc-site/index.html` в браузере (Chrome, Edge, Firefox).
2. Или запусти статический сервер в папке `ai-sdlc-site/`:
   ```
   npx serve ai-sdlc-site
   ```
   (не требуется — сайт работает и без сервера).

## Учебный проект внутри сайта

Папка `ai-sdlc-training` внедрена целиком (полная копия):

```
training/
├── AGENTS.md                    # 8 правил проекта для агента
└── lk-context/
    ├── README.md                # оглавление: 27 разделов, 72 страницы
    └── pages/                   # 72 страницы описания ЛК «как есть»
```

Её можно открыть как проект в OpenCode (папка, где лежит `AGENTS.md`) или читать страницы прямо из раздела «Каталог LK-контекста». Правила: читать раздел и родительскую страницу, писать на языке страниц, учитывать статус ЖЦ, явно говорить об изменении as-is, перечислять предположения, не менять `lk-context/`.

## Интерактив

- **31 чекпоинт**: раздел засчитывается, когда верно отвечены все квизы и отмечен чек-лист (для аттестации — ещё и сдан экзамен).
- **Квизы** с разбором и повтором; варианты перемешиваются детерминированно.
- **Чек-листы** с сохранением отметок.
- **Самопроверка компетенций**: 10 компетенций × шкала 0–3 → уровень и рекомендация.
- **Аттестация**: 30 вопросов, порог 80% (24 из 30), разбор ответов, сертификат.
- **Глоссарий** (86 терминов) с живым поиском.
- **Каталог LK-контекста**: 72 страницы с фильтром и переходом к исходному файлу.
- **Поиск по всем материалам** (`/`), включая квизы, глоссарий, аттестацию.
- Тёмная/светлая тема, прогресс в шапке, навигация ← →, экспорт/импорт и сброс прогресса, печать.

Прогресс хранится в `localStorage` (ключ `ainsdlc.v1`) и никуда не отправляется.

│   ├── data-roles.js     # плейбуки продукта, QE, инженера

│   ├── data-final.js     # самопроверка, аттестация, глоссарий
│   ├── data-library.js   # карта документации, пробелы, конспекты

    └── lk-context/{README.md, pages/*.md}
