Описание
========

Рекламный трафик не шаблонируется, поэтому обычные Viber-сообщения стоят дорого. Есть возможность отправлять Viber-сообщения по сниженной цене, но они должны соответствовать правилам и должны быть согласованы на стороне Viber. Шаблон создаётся, согласуется и используется для имени отправителя Viber из этого же приложения. У одного имени может быть неограниченное кол-во шаблонов. Шаблоны создаются бесплатно, общее кол-во на приложение не ограничено. После согласования при отправке Viber-сообщения сверяется текст шаблона и текст сообщения. Если совпадают, Viber-сообщения тарифицируется как сервисное. Если не совпадают, сообщение отправляется и тарифицируется как рекламное.

Шаблон должен быть уникален по следующим параметрам:

* имя отправителя;
* текст шаблона

**Список шаблонов Viber**

Я как пользователь хочу просмотреть список шаблонов Viber, чтобы найти нужный и посмотреть детали или добавить новый

**Описание**

В списке отражены все шаблоны Viber приложения. Во вкладке доступно общее количество шаблонов. Есть ссылка с инструкцией, открывается в модальном окне.
Если ни одного шаблона не добавлено, доступна иллюстрация.
Если ни одного имени Viber не добавлено в приложение, доступна ссылка на добавление имени, ведет на стр регистрации имени Viber в этом приложении в текущей вкладке.
Пагинация появляется если в списке больше 11 строк.

Добавить новый шаблон может только активный пользователь. Для пользователей в фин/адм блоке кнопка "Добавить" заблокированы.

Для активных пользователей доступно массовое отключение активных и неактивных шаблонов с помощью чекбоксов. Для пользователей в фин/адм блоке чекбоксы массового действия заблокированы

**Редактирование отклонённого шаблона Viber**

Я как пользователь хочу отредактировать отклонённый шаблон, чтобы отправить его на повторное согласование Viber

**Описание**

В случае отклонения шаблона со стороны Viber шаблона автоматически переходит в статус "Отклонен" и клиент может отправить заявку на повторное согласование. Статус "Отклонён" не ограничен по времени. Возможно получить отказ от Viber и снова отправить заявку неограниченное количество раз.

По факту отклонения клиенту отправляется сервисная нотификация на email, на который зарегистрирован аккаунт. Письмо содержит ссылку, которая ведёт на страницу редактирования заявки этого шаблона.

Отключение шаблона
==================

Отключение шаблона

**Отключение шаблона Viber из карточки**

Я как пользователь хочу отключить шаблон, потому что больше не отправляю такие сообщения из карточки

**Описание**

Фактическое удаление не предусмотрено, т.к. важно сохранить историю согласований. Терминальный статус — отключение. Сначала статус шаблона меняется на "Отключён" на стороне Exolve, затем отправляется оповещение в сторону Omni, а Omni — операторам. Viber-сообщения тарифицируются как рекламные сразу после отключения на стороне Exolve.

Шаблон могут отключить активные пользователи, при этом статус шаблона должен быть "Активный"/"Неактивный"
