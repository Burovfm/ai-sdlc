# Синтезированная речь

|  |  |  |  |
| --- | --- | --- | --- |

Описание
========

INLINE

Синтез речи (TTS) используется в голосовых услугах в качестве альтернативы загруженного в библиотеку аудиофайла. Возможно как синтезирование речи на лету в рамках конкретного запроса, так и добавление промтов в библиотеку приложения как "заготовки" для последующего использования.

Промт — ресурс приложения. Каждому добавленному промту присваивается уникальный ID, который используется в запросе.

Тарификация происходит при проигрывании промта в рамках голосовой услуги. Деньги за добавление промта в библиотеку не взимаются.

Удаление синтезированного промта

Удаление синтезированного промта
================================

Я как пользователь хочу удалить промт, чтобы не пользоваться им больше (из карточки)

**Описание**

Удаление промта доступно только для активных и потенциальных пользователей.
Поскольку связки между услугами и промтами нет сейчас, поэтому просто удаляем промт даже если он привязан к услуге. Если промт удалён когда он проигрывается в рамках услуги, аудио проигрывается до конца не прерываясь, потому что уже скачано. Новые звонки с удалённым промтом всё равно инициируются, но с тишиной
