Описание услуги
===============

INLINE

**Telegram Verify** — сервис, позволяющих отправлять коды подтверждения в официальный канал Telegram «Verification Codes» с помощью API-метода [SendMessage](https://docs.exolve.ru/docs/ru/api-reference/sms-api/sending-message/).

**Юридическое обоснование:**

**Q:** Номер телефона — персональные данные, код подтверждения — тайна связи. Имеет ли МТТ право работать с этими кодами?
**A:**МТТ может работать с кодам подтверждения в силу положений ст. 53 и 63 ФЗ «О связи». Клиент при этом обязуется

**Q:** По 41-ФЗ гос.органам, банкам, фин.организациям, операторам связи запрещено информировать граждан через иностранные мессенджеры. Telegram зарегистрирован не в РФ, так что тоже попадает под это требование?
**A:** Оператор связи и его работники не вправе осуществлять информирование об услугах связи своих клиентов через иностранные мессенджеры. На рассылку кодов и любых других сообщений это *не* распространяется, поскольку это взаимодействие заказчика рассылки (клиента услуги) и адресата (клиента заказчика рассылки). МТТ как оператор в данном случае только предоставляет инструмент.

**A:** Кто несёт ответственность за соблюдение требований по обработке персональных данных?
**Q:** Клиент обязуется соблюдать требования законодательства об обработке персональных данных и собирать согласия абонентов перед отправкой уведомлений. Это обязательство указано в документе [«Условиях использования сервиса "Омниканальные коммуникации"»](https://exolve.ru/faq/terms-of-service-omnichannel-communications/), с которыми клиент соглашается при подключении услуги Telegram Verify.

Механика работы
---------------

1. Клиент (бизнес) подключает услугу в Личном кабинете в разделе «Каналы» → «Telegram»
2. Конечный потребитель в форме входа/регистрации  в сервис клиента МТС Exolve вводит номер своего телефона и запрашивает код подтверждения
3. Сервис клиента передает по API с помощью метод SendMessage в сторону МТС Exolve запрос на отправку кода этому потребителю. Во входных параметрах указываются мобильный номер получателя и код (строго цифры, от 4 до 8 символов) для подтверждения действия
4. МТС Exolve формирует и отправляет запрос на отправку этого сообщения в Telegram
5. Telegram отправляет конечному потребителю указанный код в официальный канал Verification Codes
6. Telegram возвращает в МТС Exolve статус доставки
7. МТС Exolve списывает средства за доставленное сообщение с баланса пользователя
8. Сервис клиента проверяет корректность ввода кода конечным потребителем
9. Детали сообщения доступны для клиент по API и в ЛК МТС Exolve
