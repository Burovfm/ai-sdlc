# Госуслуги

Подписание через Госуслуги доступно для ФЛ и ИП, процессы совпадают.

Краткий процесс:

1. Пользователь авторизуется в своём аккаунте Госуслуг — сервис автоматически забирает его данные и заполняет ими анкету для договора
2. Формируется заявка на ручную верификацию этих рег.данных в CRM. Возможные статусы закрытия заявки:
   1. Успешно — пользователю доступно подписание договора в ЛК
   2. Требуются доп.подтверждающие документы — пользователь должен загрузить указанные документы в ЛК для продолжения подписания
   3. Отказано в подписании — пользователь не может подписать договор, при этом аккаунт не блокируется
3. Пользователь подписывает договор эл подписью кликом по кнопке
4. Аккаунт активирован, сняты ограничения тестового периода

Сиквенс:

Кликнуть «Получить полный доступ» в баннере под шапкой сайта или перейти в раздел подписания договора.

Выбрать правовую форму «Физлицо», способ подписания — «Онлайн, через Госуслуги».

Кликнуть «Заполнить через Госуслуги», чтобы сервис забрал данные пользователя из ГУ и автоматически заполнил ими договор.

Подтвердить заполнение данных для договора с помощью Госуслуг.

Авторизоваться в Госуслугах.

Дождаться загрузки данных из Госуслуг. Данные проходят автоматически проверку на: признак «фрод», терроризм, недействительный паспорт.

Проверить корректность загруженных из Госуслуг данных. Если есть неактуальные данные, обновить их в аккаунте Госуслуг, затем в ЛК МТС Exolve кликнуть «Обновить данные с Госуслуг» — сервис загрузит обновлённые данные. В ЛК МТС Exolve можно при необходимости изменить номер телефона и почтовый адрес.

Кликнуть «Подписать договор».

Подтвердить корректность данных. Изменить данные в договоре потом можно будет только через ручной процесс.

В CRM автоматически сформирована заявка на ручную верификацию рег.данных. В ЛК МТС Exolve для просмотра в PDF доступен договор, заполненный данными из Госуслуг.

В CRM найти заявку контрагента по ЛС или ФИО. Выбрать себя отвественным.

Выбрать результат верификации по клику на лупу снизу — откроется окно с вариантами.

Перевести заявку на следующий этап.

Выбрать статус закрытия заявки. Сохранить.

В случае успешной верификации рег.данных в ЛК МТС Exolve станет доступно подписание договора электронной подписью. Подписать договор кликом на кнопку.

Сразу после подписания договора аккаунт активирован: ограничения тестового баланса сняты, тестовый баланс обнулён, доступно пополнение баланса. Действие логируется в Журнале действий.
На email отправлено письмо с уведомлением об активации аккаунта.
