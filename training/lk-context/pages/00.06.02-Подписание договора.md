# Подписание договора

Описание
========

INLINE

После регистрации пользователя автоматически начинается тестовый период и начисляется тестовый баланс. Чтобы получить полный доступ к платформе, снять ограничения на коммуникации и пополнять баланс, необходимо подписать договор:

* Как юрлицо через ЭДО
* Как ИП через ЭДО или Госуслуги
* Как физлицо через Госуслуги

Для этого пользователь:

1. Заполняет свои данные
2. Данные проходят проверку на уже имеющийся активный договор в Exolve и автоматическую верификацию↗:
   1. Фрод :
      * ФЛ: ИНН (ищется как ИП) и паспортные данные + дата рождения
      * ИП: ИНН ипаспортные данные + дата рождения (ищется как ФЛ)
      * ЮЛ:ИНН+КПП
   2. Терроризм:
      * ФЛ/ИП: паспортные данные или фио+дата рождения
      * ЮЛ: ИНН+название организации
   3. Утерянный паспорт: паспортные данные
   4. Ликвидация организации
3. Данные проходят ручную верификацию
4. Подписывается договор

Пользователь переходит в раздел подписания договора кликнув по одной из ссылок/кнопок «Подтвердить аккаунт»

Пользователь выбирает правовую форму для подписания договора. В зависимости от выбранной формы будут отличаться поля для заполнения на следующих шагах

Даты договора
-------------

| Дата | Сервис/место | Описание |
| --- | --- | --- |
| Дата договора | В шапке рег.формы | Используется как идентификатор договора вместе с номером |
| Дата подписания | В CRM | Должна совпадать с датой в шапке рег.формы |
| Дата фактического подписания | В штампе ЭДО | Может значительно отличаться от даты в шапке рег.формы |
| Дата заключения договора | В Onyma | От неё рассчитываются все платы Может отличаться от даты фактического подписания на 1-2 раб. дня |
| Дата активации ЛС | В Onyma | Используется для формирования отчётных документов.  Должна совпадать с датой фактического подписания договора (в шапке рег.формы и в CRM) |
| Дата активации ЛС | В СМА / LC |  |
| Дата формирования | «Мои документы» в ЛКР | Дата формирования договора (создание 1-й заявки на верификацию) |
