# История звонков

Введение
========

История звонков — бесплатный инструмент, при помощи которого клиент может получать информацию по потреблению звонковых услуг Exolve. Предоставляется в табличном виде с фильтрами для выбора. Доступ в раздел у пользователя есть всегда, независимо от статуса по Жизненному Циклу.

Пользователь при переходе в раздел видит данные за последние 3 дня с возможностью выбрать в календаре другой период времени. Данные накапливаются по мере пользования услугами. Максимальная глубина хранения — 3 года. Данные, выходящие за пределы этого периода, удаляются.

Пользователю для просмотра доступны все звонки, совершённые за последние 3 года даже если услуга как сущность (callback звонок или голосовое SMS), номер телефона или приложение, к которому был привязан номер, удалены.

Документация по API-методам в Сообществе: [Statistics API](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/)↗

Описание
========

Статистика звонков доступна в разделе приложения «Статистика» → «Звонки». Отражён список всех звонков с/на номера этого приложения с возможностью фильтрации.

У каждого звонка есть карточка с деталями: информация о звонке (ID, дата, номера), запись разговора, текстовая расшифровка и результаты речевой аналитики (если услуги были подключены до совершения звонка и срок хранения не истёк)

*Параметры таблицы*

* Идентификатор вызова (call\_id)
* Дата и время начала звонка (московское время)
* Кто звонил
* Кому звонили
* Длительность вызова
  + Общая длительность — интервал времени, включающий ожидание и ответную фазу
  + Ожидание — интервал времени до фактического ответа вызываемого абонента, включает проигрывание аудиосообщения
  + Ответная фаза — интервал времени с фактического ответа вызываемого абонента до разрыва соединения
* Направление
  + Исходящее
  + Входящее
* Статус звонка\*
* Услуга
  + Callback звонки
  + Переадресация входящих вызовов
  + Голосовые SMS
  + SIP-звонки

*Статусы звонков*

| **Статус** | **Описание** |
| --- | --- |
| Принят | Соединение установлено, вызываемый абонент ответил на звонок |
| Отменён | Соединение установлено, но один из абонентов отменил вызов до таймаута оператора |
| Недоступен | Соединение установлено, но вызываемый абонент вне зоны действия сети или его аппарат отключен |
| Нет ответа | Соединение установлено, но вызываемый абонент не ответил до таймаута оператора |
| Занят | Связь с оператором установлена, но линия вызываемого абонента занята |
| Ошибка соединения | Соединение не установлено (неверный номер или точка назначения недоступна) |

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Раздел доступен для пользователей всех статусов по ЖЦ
