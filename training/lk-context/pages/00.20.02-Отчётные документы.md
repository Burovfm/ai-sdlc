# Отчётные документы

Описание
========

Пакет бухгалтерских документов за прошлый отчётный период формируется автоматически для ЮЛ/ИП до 5 числа каждого месяца. Авансовый пользователь может скачать архив с документами в формате PDF (счёт-фактура, акт выполненных работ, детализация). Ежеквартально также формируется акт сверки. Пользователь может найти документы за нужный период используя календарь.

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Раздел доступен для потенциального пользователя для просмотра
* Раздел доступен ЮЛ/ИП в статусах активных, заблокированный и замороженный
