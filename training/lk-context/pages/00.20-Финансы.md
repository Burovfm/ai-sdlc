# Финансы

Введение
========

В разделе “Мои финансы” пользователь может просмотреть информацию по своему текущему балансу, расходам и платежам, доступным способам оплаты и отчётным документам.

Описание
========

Раздел состоит из подразделов:

* Обзор — номер лицевого счёта, текущий баланс, суммарная абонентская плата, расходы за текущий и предыдущий месяцы
* Пополнение баланса — пополнение баланса картой или формирование счёта
* История платежей — список операций пополнения баланса
* Отчётные документы — пакеты документов (счёт-фактура, детализация, акт выполненных работ) за прошлые отчётные периоды (только для ЮЛ/ИП)

Обзор
-----

Точки входа в “Мои финансы” → “Обзор”:

1. Пользователь кликает на текущий баланс в шапке
2. Пользователь кликает на иконку профиля в шапке → в открывшемся боковом меню кликает “Мои финансы”
3. Пользователь кликает “Подробнее” в блоке “Финансы” на Главной странице

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Потенциальный пользователь может просмотреть финансовую статистику по расходам тестового баланса, доступные способы оплаты для разных правовых форм и увидеть из чего состоят разделы. Операция пополнения баланса недоступна.
* Для активного пользователя (ФЛ) недоступен раздел “Отчётные документы” и формирование счёта
* Пользователь в финансовой блокировке может пополнить баланс удобным способом. Доступен просмотр истории расходов, платежей и отчётных документов за прошлые периоды
* Пользователь в административной блокировке или заморозке не может пополнить баланс. Доступен просмотр истории расходов, платежей и отчётных документов за прошлые периоды
