# Транскрибация

Введение
========

INLINE

Транскрибация или расшифровка — перевод речи из аудио в текст. Разговор записывается, после завершения сохраняется как аудиофайл и расшифровывается. Это позволяет отделу качества вместо длительного прослушивания каждого звонка быстрее и качественнее анализировать работу сотрудников поддержки и менеджеров.

В МТС Exolve для транскрибации в качестве поставщика используется Yandex SpeechKit. Распознавание асинхронное.

Получить текстовую расшифровку можно по API или в Личном кабинете в разделе «Статистика» → «История звонков».

Документация по API-методам в Сообществе: [Call Transcribation API](https://docs.exolve.ru/docs/ru/api-reference/call-transcribation-api/)↗

Описание
========

Подключение
-----------

Текстовая расшифровка разговора напрямую связана с его аудиозаписью. Транскрибировать возможно только те звонки, которые записывались, поэтому перед подключением услуги расшифровки удостоверьтесь, что в приложении и на определённом номере подключено хранение записей разговоров.

Подключить услугу можно по API, применив метод [SetCallTranscribationState](https://docs.exolve.ru/docs/ru/api-reference/call-record-api/setting-transcribation-state/) ↗, или в Личном кабинете. Для подключения расшифровки в ЛК активируйте переключатель в блоке «Текстовая расшифровка звонков» в настройках приложения. После этого услугу можно подключить на конкретном номере этого приложения в его карточке.
По умолчанию расшифровка на номерах отключена.

Получение расшифровки
---------------------

Получить расшифрованный разговор можно по API с помощью метода [GetTranscribation](https://docs.exolve.ru/docs/ru/api-reference/call-record-api/getting-transcribation/) ↗ или в Личном кабинете в разделе «Статистика» → «История звонков». Расшифровка хранится столько же месяцев, сколько и аудиозапись разговора. После истечения срока хранения и запись разговора, и расшифровка автоматически удаляются.
Срок формирования транскрибированной записи – не более 24 часов.

Онлайн-уведомления о готовности расшифровки
-------------------------------------------

По готовности транскрибации возможно получать уведомления на URL-адрес в режиме онлайн. Такие уведомления доступны бесплатно для потенциальных и активных пользователей в рамках всех голосовых услуг. [Подробнее в документации](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/call-events/) ↗

Отключение
----------

Услугу можно отключить глобально для всех номеров приложения в настройках приложения или только на конкретном номере в его карточке. Отключение доступно как в ЛК, так и по API через установка параметра call\_transcribation «false» при вызове метода [SetCallTranscribationState](https://docs.exolve.ru/docs/ru/api-reference/call-record-api/setting-transcribation-state/) ↗.
Звонки, совершённые после отключения услуги, не транскрибируются. Расшифровки, созданные до отключения, продолжают хранится до истечения своего срока.
Транскрибация отключается автоматически при отключении хранения записей разговора.

Тарификация
-----------

Услуга подключается бесплатно. Плата списывается за каждую транскрибированную минуту с баланса аккаунта после завершения вызова. Применяется округление до 1 минуты: звонок длительностью 01:01 или 01:59 оплачивается как 2 мин. На состояние 2023г. тарифицируется полная длительность разговора, включая КПВ (гудки).
[Тарифы](https://exolve.ru/tariffs/) ↗
