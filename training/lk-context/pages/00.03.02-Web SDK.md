# Web SDK

Введение
========

INLINE

Web Voice SDK (Web SDK) — готовая библиотека, позволяющая быстро интегрировать голосовые API МТС Exolve в веб-приложение клиента, чтобы совершать и принимать звонки в окне браузера через SIP-соединение на базе технологии WebRTC (высокое качество связи без помех и эха). Клиенту не придётся самостоятельно разрабатывать звонковый функционал с нуля.

Услуга подключается бесплатно. Оплачиваются только исходящие вызовы в соответствии с [Тарифами](https://exolve.ru/tariffs/) ↗.

Ссылка на демо: <https://mtsexolve.github.io/web-voice-sdk/>

[Документация в Сообществе](https://docs.exolve.ru/docs/ru/web-sdk/).

Описание
========

Краткий сценарий использования
------------------------------

1. Создать веб-приложение
2. Купить номер в МТС Exolve
3. Создать SIP-соединение в МТС Exolve, выбрать купленный номер определяемым (номер нужен для исходящих вызовов с выходом в ТфОП — его увидит принимающий абонент)
4. Выгрузить проект ExolveVoiceDemo из публичного репозитория GitHub
5. Запустить веб-приложение и зарегистрировать SIP, введя его юзернейм/пароль
6. Совершить звонок

Детали звонков можно получить с помощью метода [GetList](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/call-history/) ↗. Они также отражены в «Истории звонков» в Личном кабинете с категорией «SIP».
