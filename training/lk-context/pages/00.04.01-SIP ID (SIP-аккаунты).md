Введение
========

INLINE

SIP ID (SIP-аккаунты) — ресурсы приложений. В рамках MVP возможно создание только внутренних SIP-аккаунтов.  SIP-аккаунт создаётся для получения автоматически сгенерированных учётных данных (юзернейм и пароль). Пользователь авторизуется с ними на своём оборудовании, чтобы устанавливать сеансы связи через SIP-протокол.

SIP ID — идентификатор протокола VoIP (голосовое общение посредством интернета), используемый для идентификации пользователя в сети SIP. SIP ID является уникальным идентификатором пользователя, который позволяет установить исходящие и принимать входящие голосовые или видео вызовы через сеть SIP.

SIP (Session Initiation Protocol) — протокол установления сеанса связи, позволяющий пропускать больший объём данных через один канал и минимизировать расходы.

В API платформе MTC Exolve имеются следующие ограничения по объему исходящего трафика вызовов с SIP ID:

* Для ЮЛ и ИП – 5 cps и 300 sl
* Для ФЛ – 0,3 cps и 3 sl  (= максимум 3 инициации вызова в промежутке 10 секунд и 3 активных исходящих вызова)

Ограничения устанавливаются на уровне каждого SIP ID, а также на уровне приложения (т.е. совокупный объем вызовов с разных SIP ID внутри одного приложения не может превышать указанные ограничения)

Документация по API-методам в Сообществе: [SIP API](https://docs.exolve.ru/docs/ru/api-reference/sip-api/)↗

Описание
========

SIP ID — один из двух типов SIP-соединений в МТС Exolve. Управлять SIP ID можно с помощью [SIP API](https://docs.exolve.ru/docs/ru/api-reference/sip-api/) ↗, в ЛК — в разделе «SIP-соединения» → «SIP ID». Там отражён список всех созданных в этом приложении SIP ID, у каждого доступна карточка с деталями.

Поддерживается мультирегистрация сипов, т.е. например, при осуществлении авторизации под одним и тем же SIP ID  на разных устройствах входящий звонок на номер, у которого настроена переадресация на данный SIP ID, отобразится на обоих устройствах.

### Создание

SIP ID как ресурс могут создать потенциальные и активные пользователи по API с использованием метода [Create](https://docs.exolve.ru/docs/ru/api-reference/sip-api/creating-sip/) ↗ и в ЛК в разделе «SIP-соединения». SIP ID (наряду с номером и SIP-транком) — ресурс приложения. Потенциальный пользователь может создать только 3 SIP ID, для активного ограничений на кол-во ни в приложении, ни в аккаунте в целом нет.

При создании требуется указать:

* Внутреннее название, чтобы быстрее найти этот ресурс в списке SIP ID (обязательно). Название должно быть уникальным в рамках приложения
* Определяемый А-номер для исходящих вызовов (обязательно). Номер выбирается среди номеров, купленных в этом же приложении. 1 номер может быть выбран определяемым для нескольких SIP ID
* Вкл/выкл услугу хранения записей разговоров (опционально). ЗР на SIP ID может быть включена, только если эта услуга подключена глобально в этом приложении

В результате система МТС Exolve автоматически генерирует юзерйнейм формата 883140ХХХ и пароль.

### **Использование**

Исходящие вызовы доступны по умолчанию, приём входящих — только в рамках переадресации. Переадресация на SIP ID устанавливается в настройках номера по API с использованием метода [SetCallForwarding](https://docs.exolve.ru/docs/ru/api-reference/numbering-api/call-forwarding/) ↗ и в ЛК. Для выхода в ТфОП при исходящем вызове принимающий абонент видит определяемый номер, выбранный в настройках этого SIP-транк, но возможно «на лету» передать другой номер на оборудовании клиента. В любом случае определяемый номер должен быть куплен в том же приложении, где создан этот SIP ID.

Детали звонков можно получить с помощью метода [GetList](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/call-history/) ↗. Они также отражены в «Истории звонков» в Личном кабинете с категорией «SIP».

### **Изменение**

С помощью метода Update можно изменить внутреннее название (2024), с помощью [ChangePassword](https://docs.exolve.ru/docs/ru/api-reference/sip-api/changing-password/) ↗ — автоматически сгенерировать новый пароль. Редактирование доступно для потенциального и активного пользователей. При обновлении SIP ID применяются те же правила, что и при создании.

### Тарификация

В рамках каждого приложения аккаунта возможно создать 3 бесплатных SIP ID. За 4-й и последующие в приложении взимается абонентская плата 90₽/мес, платы за подключение нет. В приложении всегда есть «несгораемо» бесплатные аккаунты. Например: в приложении создано 10 SIP ID, затем 1 из них был удалён. Остаётся 3 бесплатных и 6 платных SIP ID.
Тарифицируются исходящие вызовы, совершённые с использованием этого SIP ID в соответствии с [Тарифами](https://exolve.ru/tariffs/) ↗. Переадресованные вызовы оплачиваются как исходящие.

### Удаление SIP ID

Для удаления SIP ID по API применяется метод [Delete](https://docs.exolve.ru/docs/ru/api-reference/sip-api/deleting-sip/) ↗. В ЛК возможно удалить SIP ID:

1. В карточке SIP ID: кликнуть на иконку с тремя точками в правом верхнем углу → подтвердить удаление в модальном окне
2. В списке SIP ID:
   1. При наведении на SIP ID отражена иконка мусорки → подтвердить удаление в модальном окне
   2. Отметить галочками SIP ID на удаление → подтвердить удаление в модальном окне

Ресурс удаляется безвозвратно. Звонки на/с удалённого SIP ID (в том числе переадресованные) невозможны. Удаление доступно только для потенциального и активного пользователей. Возможно как единичное, так и массовое удаление.
АП за оставшиеся дни месяца сразу автоматически возвращается на баланс пользователя.
