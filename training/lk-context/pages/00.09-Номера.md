Введение
========

INLINE

Номера — ресурс, который покупается и используется в рамках приложения. Пользователь может купить неограниченное количество номеров по платежной модели Pay-as-you-go.

* Для выбора доступны многоканальные городские номера 174 городов России, мобильные номера  83 регионов и интеллектуальные номера 8-800
* Номер приобретается и настраивается для конкретного приложения и является его ресурсом.
* Доступен фильтр по номеру, типу номера, региону и категории.
* Есть карточка номера, в которой указаны его характеристики, дата покупки. В ней можно включить переадресацию и запись разговоров.

Доступна возможность добавления номеров в чёрный список.

История  по вызовам, совершённым с купленного номера / принятым на купленный номер, отображается в разделе "История звонков" ЛК Р.

Документация по API-методам в Сообществе: [Numbering API](https://docs.exolve.ru/docs/ru/api-reference/numbering-api/)↗

Описание
========

Покупка номера
--------------

### Точки входа

1. Пользователь кликает “Приложения” в шапке → переходит на страницу “Мои номера” (номера всех приложений) → кликает “Купить номер” → выбирает приложение, для которого покупается номер → переходит на страницу поиска номера
2. Пользователь переходит в карточку приложения → кликает вкладку “Номера” → переходит на страницу с номерами этого приложения → кликает “Купить номер” → переходит на страницу поиска номера
3. Пользователь переходит в карточку приложения → кликает “+Номер” в блоке быстрого добавления на странице “Обзор” → переходит на страницу поиска номера
4. Пользователь переходит в карточку приложения → кликает “+Купить” в блоке “Номера” на странице “Обзор” → переходит на страницу поиска номера

### Ограничения в зависимости от статуса по ЖЦ

* Потенциальный пользователь может купить только 1 номер телефона. При покупке списывается АП, плата за подключение не взимается. Номер закрепляется на 30 дней. Удалить такой номер телефона нельзя. Если пользователь в течение этого времени не заключил договор, он попадает в финансовую блокировку. С момента блокировки номер сохраняется за ним ещё 30 дней, потом открепляется и попадает в карантин
* Активный пользователь может купить неограниченное количество номеров. Нет ограничений на удаление номера. Данные по звонкам и сообщениями этого номера хранятся в течение 3 лет, записи разговоров — до конца выбранного срока
* Заблокированный и замороженный пользователи не могут ни купить новый номер, ни отказаться от уже купленного

### Покупка номера (для активного)

* Покупка доступна как через интерфейс, так и по API
* В ЛК за 1 покупку возможно приобрести 10 номеров
* Номер покупается *в* приложении. Т.е. перед переходом на страницу поиска номера пользователь должен создать хотя бы 1 приложение
* Функционала корзины нет. Номера бронируются на 15 минут после нажатия на кнопку "Купить" на странице поиска
* Для оплаты на балансе должно быть достаточно средств для оплаты. При покупке с баланса пользователя списывается сумма, способ оплаты *не* выбирается
* Бланк заказа не формируется, покупка логируется в Журнале действий

### Доступные фильтры поиска номера

* Поиск по номеру (номер полностью, цифры, регулярное выражение)
* Фильтрации по типу (Городские / Мобильные / 8-800)
* Фильтрация по региону
* Фильтрация по категории (Обычные / Серебряные / Бронзовые / Золотые / Платиновые / Эксклюзивные)
* Можно применить по 1 параметру в фильтрах “Тип”, “Регион”, “Категория”. Например, найти сразу и золотые, и платиновые / и мобильные, и городские номера не удастся

Перед непосредственной покупкой доступна сводка покупаемых номеров с их характеристиками и стоимостью. Стоимость подключения взимается в полном объёме, абонентская плата — исходя из оставшихся дней текущего месяца. Если выбранные для покупки номера уже недоступны (были куплены), они будут перечислены в модальном окне.

### Покупка номера (для потенциального)

* Возможно купить только 1 номер обычной категории
* Перед покупкой номера пользователь должен подтвердить свой номер телефона кодом из SMS
* Номер покупается *в* приложении. Т.е. перед переходом на страницу поиска номера пользователь должен создать приложение
* Для поиска доступны номера из общего пула без ограничений
* Плата за подключение *не* списывается, только АП в соответствии с оставшимися днями месяца
* Покупка осуществляется на тестовые деньги
* Потенциальный пользователь переходит в финансовую блокировку когда на его тестовом балансе не хватает средств для списания АП в новом месяце

*Пример*: стандартный тестовый баланс 300₽. Пользователь покупает номер 15 декабря — с баланса списывается АП 75₽ за оставшиеся две недели месяца (50% от установленной АП).  Если на балансе пользователя есть доступные средства, 1 января АП списывается в полном объёме (150₽). Если пользователь в течение января не подписал договор и не пополнил баланс, 1 февраля он переходит в финансовую блокировку, т.к. на балансе недостаточно средств для списания АП. Номер сохраняется за пользователем в течение следующих 30 дней. Если в течение этого времени (до 1 марта) пользователь не подписал договор и не пополнил баланс, номер открепляется и попадает в карантин

Управление номерами
-------------------

Точки входа на страницы со списком купленных номеров

1. Пользователь кликает "Номера" в шапке
2. Пользователь переходит в карточку приложения → вкладка "Номера"

### Мои номера

Список купленных номеров доступен во вкладке "Номера" с фильтрами поиска. По клику на номер пользователь переходит в карточку номера

### Карточка номера

В карточке номера доступны его детали (характеристики, дата покупки), можно также изменить настройки (включить переадресацию, запись разговоров)

Удаление номера
---------------

Пользователь может удалить номер(-а):

1. В карточке номера: кликает на иконку с тремя точками в правом верхнем углу → подтверждает удаление в модальном окне
2. В списке номеров

Важно про удаление:

* Потенциальный, заблокированный и замороженный пользователи не могут удалить номера
* В ЛК за 1 раз возможно удалить 10 номеров
* Отказ от номера осуществляется мгновенно, денежные средства за оставшиеся дни месяца возвращаются на баланс пользователя
* При удалении приложения безвозвратно удаляются и его номера
* При удалении номера сохраняются истории звонков по нему в течение 3 лет, записи разговоров — до конца выбранного периода
* Документы при удалении *не* формируются, действие логируется в Журнале действий
