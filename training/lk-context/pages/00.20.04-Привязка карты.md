Описание
========

Для ускорения процесса пополнения баланса доступен функционал привязки банковской карты к аккаунту пользователя.

Требования
==========

Банковскую карту к аккаунту могут привязать активные пользователи любой правовой формы. Количество привязанных карт неограниченно. Информация о всех привязанных картах хранится в разделе  "Сохранённые карты" Единого профиля.

Автоплатёж на оплату конкретной услуги/ автопополнение баланса с привязанной банковской карты настраивается в ЛК того продукта, из которого будет потребляться услуга.

Use cases:

1. Если Клиент добавляет новый способ оплаты, то он автоматически становится доступен для использования в тех ЛК, в которых УЗ имеет соответствующий для этого функционала статус ЖЦ (привязка банк. карты). Т.е., например, если статус УЗ не предполагает возможность использования карты (в случае с Exolve - статус Potential, Blocked (admin), Frozen), то Клиент не сможет воспользоваться картой. Проверка доступа производится на уровне продукта (не на уровне ЕП)

Метод в PayOnline
-----------------

Оплата с уже использованной ранее карты без повторного ввода данных карты («Оплата в один клик») реализуется через метод API – rebill ([ссылка](http://developers.payonline.ru/#/api?id=%d0%9c%d0%b5%d1%82%d0%be%d0%b4-rebill) на документацию PayOnline) – в котором передаётся заполненный параметр RebillAnchor.
