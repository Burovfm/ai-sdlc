# Изменение данных договора

### Ручной процесс

1. Клиент отправляет заявку на изменение данных в договоре через менеджера или техподдержку
2. Менеджер / сотрудник ДКС / сотрудник BackOffice создаёт заявку на верификацию данных, приложив в неё новые данные клиента

* Бизнес-сервис: Процедуры
* Сервис: Проверка регистрационных данных
* Продукт: Exolve

3. Сотрудник отдела верификации проверяет данные:

* Согласовано: закрывает заявку — можно менять данные
* Не согласовано: закрывает заявку и блокирует аккаунт из-за фрода
* Согласовано с комментариями:

4. Сотрудник BackOffice меняет данные в Onyma
5. Сотрудник BackOffice меняет данные в CRM
6. Сотрудник BackOffice меняет данные в ЛКМ

6.1. Перейти в карточку клиента → «Данные договора» и нажать на иконку карандаша в правом нижнем углу.

6.2. Ввести нужные данные и сохранить их.

Таким образом, заявки на ДПР в Jira можно создать только при необходимости изменения даты договора. Все остальные данные (кроме ИНН и ОГРН для ЮЛ / ИНН для ИП) можно изменить самостоятельно в ЛКМ — они обновятся в базе данных Exolve без привлечения ДПР.
