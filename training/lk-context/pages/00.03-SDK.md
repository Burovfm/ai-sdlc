# SDK

SDK (Software Development Kit) — инструментарий разработки программного обеспечения, готовые библиотеки, который позволяет разработчикам интегрировать функциональность телефонии напрямую в мобильные и веб-приложения. С помощью Mobile SDK клиент может совершать и принимать звонки прямо в своём мобильном приложении, с помощью WebSDK — в окне браузера своего веб-приложения без самостоятельной разработки этого функционала с нуля.

В Web и Mobile SDK используется стандарт WebRTC (Web Real-Time Communication) – это открытый стандарт, разработанный для мгновенной передачи голоса, видео и данных между веб-браузерами и мобильными приложениями. Стандарт WebRTC позволяет устанавливать прямое аудио- и видеосоединение между пользователями без необходимости сторонних плагинов или программ.

В рамках WebRTC Exolve возможно совершение и приём звонков через SIP-протокол.
