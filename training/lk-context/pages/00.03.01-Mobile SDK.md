# Mobile SDK

Введение
========

INLINE

Mobile Voice SDK (Mobile SDK)— готовая библиотека, позволяющая быстро интегрировать голосовые API МТС Exolve в любое мобильное приложение на базе iOS/Android/Huawei. Клиенту не придётся самостоятельно разрабатывать звонковый функционал с нуля. Библиотека позволяет совершать и принимать вызовы через SIP-соединение на базе технологии WebRTC (высокое качество связи без помех и эха) в мобильном приложении, через мобильную сеть или на стационарном телефоне.

Доступны отдельные SDK для [Flutter](https://docs.exolve.ru/docs/ru/mobile-sdk/flutter/) и [ReactNative](https://docs.exolve.ru/docs/ru/mobile-sdk/react-native/).

Звонки поступают в push-уведомлениях телефона, через которые можно принять или отклонить вызов. Такое уведомление о звонках содержит номер, имя (если пользователь уже есть в контактах) и аватар. Для получения звонков конечный пользователь моб.приложения при его установке должен согласиться получать push-уведомления.

МТС Exolve общается не напрямую с моб. приложением клиента, а с его бэкендом. Клиенту МТС Exolve необходимо самостоятельно разработать бэкенд приложения, на котором будет храниться связка идентификатора устройства конечного пользователя (device\_id) и моб.приложения. Клиент по API отправляет нужную для звонка информацию (идентификатор, тип устройства и sip) в сторону МТС Exolve.

[Документация в Сообществе](https://docs.exolve.ru/docs/ru/mobile-sdk/).

Описание
========

Доступно:

* Исходящие звонки (на ABC/DEF/SIP ID)

  + позвонить
  + завершить/сбросить вызов
* Входящие звонки

  + принять
  + завершить/отклонить

Виброрежим и рингтон пользователь должен реализовывать на своей стороне самостоятельно.

Неофициально

| Функционал | Комментарии |
| --- | --- |
| Удержание вызова   * постановка * снятие |  |
| Холодный перевод вызова на номер/sip id | перевод производится через вызов по uri   1. перевод недоступен для звонящего, а доступен только принимающему |
| Отправка DTMF символы (0-9, A, B, C, D, символы: \* или #) |  |
| Конференция   * создание * объединение вызова в конференцию с другим вызовом * исключение вызова из конференции | 1. лимит по числу участников конференции: 5 линий 2. при включении в звонок второй линии первая ставится на удержание, есть возможность через drag&drop объединить вызовы 3. добавление новой линии происходит через 2 клика 4. для организатора доступно завершение вызова для всех участников 5. во время дозвона одному участнику недоступно добавление другого; добавление другого доступно только если соединение с другими уже установлено (добавление только в уже существующую) |

Краткий сценарий использования
-----------------------------

Инструкция по старту работы с Mobile SDK в Сообществе: <https://community.exolve.ru/faq/mobile-sdk/>

1. Создать моб.приложение на нужной платформе (iOS, Android, Huawei)
2. Купить номер в МТС Exolve
3. Создать SIP ID в МТС Exolve, выбрать купленный номер определяемым. Нужен для исходящих вызовов с выходом в ТфОП — его увидит принимающий абонент
4. Добавьте авторизационные данные для отправки push-уведомлений в приложении в Личном кабинете Exolve. По API такое добавление не предусмотрено в целях безопасности. С помощью этой связки МТС Exolve будет знать, куда направить вызов

   1. Перейдите в раздел приложения «Ключи» → «Mobile SDK»

   2. Кликните «Подключить» в блоке «iOS», «Android» или «Huawei»
   3. Загрузите требуемые файлы или данные (необходимо скопировать авторизационные данные для push-уведомлений в кабинете разработчика платформы Apple, Firebase и/или AppGallery Connect)

      1. iOS = Apple. Понадобятся сертификат Apple Push Notification service (APNS) и пароль ([инструкция](https://community.exolve.ru/faq/kak-poluchit-sertifikat-apple-developer) ↗)
      2. Android = Firebase. Понадобятся ключ учётной записи (Credentials) и идентификатор проекта (Project ID) ([инструкция](https://community.exolve.ru/faq/kak-poluchit-klyuch-account-firebase) ↗)
      3. Huawei = AppGallery Connect. Понадобятся идентификатор проекта (Application ID) и API-ключ ([инструкция](https://community.exolve.ru/faq/kak-poluchit-dannye-proekta-appgallery-connect) ↗)
   4. Кликните «Подключить»
5. Выгрузить проект ExolveVoiceDemo для нужной платформы из публичного репозитория GitHub
6. В рамках этого проекта связать SIP, который будет использоваться для вызовов, с моб.приложением через Push API
7. Запустить моб.приложение и зарегистрировать SIP, введя его юзернейм и пароль (юзернейм и пароль взять из ЛК Р)
8. Совершить звонок. Конечные пользователи вашего приложения должны дать в браузере разрешение приложению на доступ к аудио.

Детали звонков можно получить с помощью метода [GetList](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/call-history/) ↗. Они также отражены в «Истории звонков» в Личном кабинете с категорией «SIP».
