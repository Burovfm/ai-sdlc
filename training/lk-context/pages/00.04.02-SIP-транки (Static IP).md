# SIP-транки (Static IP)

Введение
========

INLINE

SIP trunk – виртуальный канал связи, который используется для установления голосового или видео соединения по протоколу SIP (Session Initiation Protocol). Он позволяет организациям подключаться к общедоступной телефонной сети (PSTN) через интернет, а не через традиционные аналоговые или цифровые телефонные линии.

SIP (Session Initiation Protocol) — протокол установления сеанса связи, позволяющий пропускать больший объём данных через один канал и минимизировать расходы.

В API платформе MTC Exolve имеются следующие ограничения по объему исходящего трафика вызовов с SIP-транка (Static IP):

* Для ЮЛ и ИП – 5 cps и 300 sl
* Для ФЛ – 0,3 cps и 3 sl  (= максимум 3 инициации вызова в промежутке 10 секунд и 3 активных исходящих вызова)

Ограничения устанавливаются на уровне каждого SIP-транка (Static IP), а также на уровне приложения (т.е. совокупный объем вызовов с разных SIP-транков (Static IP) внутри одного приложения не может превышать указанные ограничения)

Документация по API-методам в Сообществе: [Static API](https://docs.exolve.ru/docs/ru/api-reference/static-api/)↗

Описание
========

SIP-транк — один из двух типов SIP-соединений в МТС Exolve. Управлять SIP-транк можно с помощью [Static API](https://docs.exolve.ru/docs/ru/api-reference/static-api/) ↗ (2023), в ЛК — в разделе «SIP-соединения» → «SIP-транк» (2024). Там отражён список всех созданных в этом приложении SIP ID, у каждого доступна карточка с деталями.

### Создание

SIP-транк как ресурс могут создать активные пользователи по API с использованием метода [Create](https://docs.exolve.ru/docs/ru/api-reference/static-api/creating-static-ip/) ↗ (2023) и в ЛК в разделе «SIP-соединения» (2024). В рамках приложения и аккаунта нет ограничений на кол-во SIP-транков. SIP-транк (наряду с номером и SIP ID) — ресурс приложения.

При создании требуется указать:

* Внутреннее название, чтобы быстрее найти этот ресурс в списке SIP-транков (обязательно)
* IP-адрес VoIP-оборудования (обязательно). Адрес должен быть уникальным для всей системы Exolve
* Порт (опционально). По умолчанию используется порт «5060», вместо него можно добавить другой порт. В 2023 для одного URL возможно указать только один порт
* Определяемый номер для исходящих вызовов (обязательно). Номер выбирается среди номеров, купленных в этом же приложении. 1 номер может быть выбран определяемым для нескольких SIP-транков

### **Использование**

Исходящие вызовы доступны по умолчанию, приём входящих — только в рамках переадресации. Переадресация на SIP-транк устанавливается в настройках номера по API с использованием метода [SetCallForwarding](https://docs.exolve.ru/docs/ru/api-reference/numbering-api/call-forwarding/) ↗ (2023) и в ЛК (2024). Для выхода в ТфОП при исходящем вызове принимающий абонент видит определяемый номер, выбранный в настройках этого SIP-транк, но возможно «на лету» передать другой номер на оборудовании клиента. В любом случае определяемый номер должен быть куплен в том же приложении, где создан этот SIP-транк.

Детали звонков можно получить с помощью метода [GetList](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/call-history/) ↗. Они также отражены в «Истории звонков» в Личном кабинете с категорией «SIP».

Чтобы записывать разговоры на SIP-транке, нужно подключить эту услугу в настройке его определяемого номера.

### **Изменение**

С помощью метода [Update ↗](https://docs.exolve.ru/docs/ru/api-reference/static-api/updating-static-ip/) можно изменить внутреннее название и IP-адрес с/без порта. Редактирование доступно для потенциального и активного пользователей. При обновлении SIP-транка применяются те же правила, что и при создании.

### Тарификация

SIP-транк создаётся бесплатно: не взимается ни плата за подключение, ни абонентская плата. Тарифицируются исходящие вызовы, совершённые с использованием этого SIP-транка в соответствии с [Тарифами](https://exolve.ru/tariffs/) ↗. Переадресованные вызовы оплачиваются как исходящие.

### Удаление

Для удаления SIP-транка применяется метод [Delete](https://docs.exolve.ru/docs/ru/api-reference/static-api/deleting-static-ip/) ↗. Ресурс удаляется безвозвратно. Звонки на/с удалённого SIP-транк (в том числе переадресованные) невозможны. Удаление доступно только для потенциального и активного пользователей. Возможно как единичное, так и массовое удаление.
