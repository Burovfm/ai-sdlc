# Карусель номеров в Exolve

Описание
========

### Описание услуги

**Карусель** – механизм, позволяющий осуществлять интеллектуальный, логический выбор исходящего номера из ресурса нумерации, выделенного абоненту по договору, при осуществлении пользователями исходящих вызовов.

Типы Карусели:

1. Карусель 1.0
2. Карусель 2.0
