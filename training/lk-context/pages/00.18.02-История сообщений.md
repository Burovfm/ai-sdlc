# История сообщений

Введение
========

История сообщений — таблица с агрегированными данными по сообщениям, отправленным и полученным по разным каналам (в MVP только SMS, в 2023 + Viber, Telegram, WhatsApp).

Пользователь при переходе в раздел видит в своих отчётах данные за последние 3 дня с возможностью выбрать в календаре другой период времени. Данные накапливаются по мере пользования услугами. Максимальная глубина хранения — 3 года. Данные, выходящие за пределы этого периода, удаляются.

Пользователю для просмотра доступны все сообщения, отправленные и принятые за последние 3 года даже если номер телефона или приложение, к которому был привязан номер, удалены.

Документация по API-методам в Сообществе: [SMS API](https://docs.exolve.ru/docs/ru/api-reference/sms-api/)↗

Описание
========

Раздел состоит из

1. Список сообщений в табличном виде
2. Карточка сообщения с деталями (в т.ч. текст)

Карточка сообщения
------------------

*Параметры*

* ID сообщения
* Дата и время отправки/приёма сообщения (московское время)
* Направление сообщения
  + Входящее
  + Исходящее
* Номер отправителя
* Номер получателя
* Статус доставки
* Канал
  + SMS
* Количество сегментов в сообщении
* Текст сообщения
* Приложение

|  |  |
| --- | --- |
| **Статус доставки** | **Описание** |
| В очереди / Queued | Новое исходящее или входящее сообщение ожидает отправки в SMS-центр |
| Отправлено / Transmitted | Сообщение отправлено в SMS-центр, SMS-центр назначил ему идентификатор (internal\_id) |
| Доставлено / Delivered | Сообщение доставлено получателю (SMS-центр отправил уведомление о доставке) |
| Неуспешно /  Failed | Сообщение не может быть доставлено получателю (SMS-центр отправил уведомление о недоставке) |

 *Параметры поиска*

* Номер (полностью или частично) / SIP ID / ID звонка
* Дата и время
* Расширенные фильтры (открываются в боковом меню слева)
  + Направление
  + Канал
  + Статус
  + Количество сегментов

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Раздел доступен для пользователей всех статусов по ЖЦ
