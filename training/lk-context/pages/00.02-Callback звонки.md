# Callback звонки

Введение
========

INLINE

Callback — телефонная услуга, позволяющая клиенту заказать соединение с нужным абонентом таким образом, чтобы звонок был входящим для обеих сторон.

Callback — ресурс приложения.

Клиент получает возможность предоставлять Посетителям возможность получить сервис обратного вызова посредством отправки в сторону Оператора команд API, инициирующих вызовы по CommonAPI в режиме реального времени.

В рамках обратного звонка клиент может:

* проигрывать информационное сообщение в сторону абонента А и/или абонента B, используя загруженный аудиофайл или синтез речи
* вызывать нескольких операторов, выбрав нужный тип дозвона: одновременно, по порядку, рандомно
* получать уведомления о ходе обратного звонка в режиме онлайн
* записывать и прослушивать разговоры каждого абонента

Документация по API-методам в Сообществе: [Callback API](https://docs.exolve.ru/docs/ru/api-reference/callback-api/)↗

Описание
========

Из чего состоит раздел:

1. Список всех созданных callback с датой создания, внутренним названием, ID
2. Карточка callback с внутренним названием, описанием, ID, шаблоном кода

Создание callback
-----------------

Пользователь может создать callback:

1. На странице “Обзор” приложения кликает на “+Callback” в блоке быстрого добавления → переходит на страницу создания нового callback
2. На странице “Обзор” приложения кликает на “+Создать callback” в блоке "Callback" → переходит на страницу создания нового callback
3. В карточке приложения переходит во вкладку “Callback” → кликает “Создать callback” на странице со списком всех callback → переходит на страницу создания нового callback

Чтобы использовать callback в своей среде разработки и находить нужный callback в Истории звонков, пользователь создаёт сущность callback в ЛК или по API. При создании сущности callback указывается его внутреннее название, чтобы его можно было быстрее найти в списке всех callback звонков. Звонку автоматически присваивается идентификатор. Также в карточке звонка генерируется стандартный шаблон кода (curl) с обязательными параметрами, в него подставляется идентификатор callback. Пользователь копирует этот шаблон (без возможности отредактировать в интерфейсе) и дополняет его в своей среде разработки нужными параметрами.

Удаление callback
-----------------

Пользователь может удалить callback:

1. В карточке callback: кликает на иконку с тремя точками в правом верхнем углу → подтверждает удаление в модальном окне
2. В списке callback:
   1. При наведении на callback показывается иконка мусорки → подтверждает удаление в модальном окне
   2. Отмечает галочками callback на удаление → подтверждает удаление в модальном окне

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Потенциальный и активный пользователи могут создать неограниченное количество сущностей callback, а также удалять их
* Заблокированный и замороженный пользователи не могут ни создать новый callback, ни удалить уже существующий. Сохраняется доступ (просмотр) к ранее созданным callback
