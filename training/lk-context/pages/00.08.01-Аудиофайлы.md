# Аудиофайлы

Введение
========

* Пользователь загружает в приложение аудиофайлы, чтобы использовать их в callback, голосовых SMS и при переадресации входящих вызовов. С помощью голосовых объявлений пользователь может без помощи менеджера рассказать своим клиентам о спецпредложении, напомнить о мероприятии или проиграть музыку для ожидания.
* Аудиофайл — ресурс приложения
* Каждому аудиофайлу после загрузки автоматически генерируется ID, которое пользователь использует в своей среде разработки
* Раздел состоит из списка всех загруженных аудиофайлов с названием, ID, размером, длительностью
* Раздел доступен внутри приложения, также есть общий список аудиайлов всех приложений

Документация по API-методам в Сообществе: [Media API](https://docs.exolve.ru/docs/ru/api-reference/media-api/)↗

Описание
========

Кодеки
------

* Для формата WAV кодек "codec": "adpcm\_ms"
* Для формата МР3 кодек "codec": "libmp3lame"

Загрузка аудиофайла
-------------------

Пользователь может загрузить аудиофайл:

1. Кликает “Аудиофайлы” в шапке → кликает “Загрузить аудиофайл” на странице со списком аудиофайлов всех приложений → переходит на страницу загрузки нового аудиофайла, выбирает в какое приложение загрузить
2. На странице “Обзор” приложения кликает на “+Аудиофайл” в блоке быстрого добавления → переходит на страницу загрузки нового аудиофайла
3. В карточке приложения переходит во вкладку “Аудиофайлы” → кликает “Загрузить аудиофайл” на странице со списком аудиофайлов → переходит на страницу загрузки нового аудиофайла

Удаление аудиофайла
-------------------

Пользователь может удалить аудиофайл:

1. В списке аудиофайлов приложения или общем списке:
   1. При наведении на аудиофайл показывается иконка мусорки → подтверждает удаление в модальном окне
   2. Отмечает галочками аудиофайлы на удаление → подтверждает удаление в модальном окне

Ограничения в зависимости от статуса по ЖЦ
==========================================

* Потенциальный пользователь может загрузить до 3 аудиофайлов. При удалении одного или всех, снова доступна загрузка
* Активный пользователь может загрузить неограниченное количество аудиофайлов
* Заблокированный и замороженный пользователи могут просмотреть и прослушать уже загруженные аудиофайлы, но не могут ни удалить их, ни загрузить новый
