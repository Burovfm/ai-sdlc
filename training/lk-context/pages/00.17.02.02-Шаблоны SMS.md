# Шаблоны SMS

С 1 сентября 2025 года оператор МТС вводит плату за обслуживание шаблонов для отправки SMS — теперь каждый шаблон любой категории, согласованный у МТС, будет стоить 1 000 ₽ с НДС в месяц.

* Абонентская плата будет списываться в полном размере вне зависимости от даты согласования
* В последующих месяцах абонентская плата будет списываться 1-го числа
* Стоимость отправки SMS не меняется
* Актуальная стоимость услуг опубликована в «Тарифах» (<https://exolve.ru/tariffs/messengers/>)

Введение
========

INLINE

**Шаблонированные SMS** – сообщения, информирующие получателей о статусе заказа, фин.операций, тех.работах, могут содержать коды/пароли для входа в сервис и пр. Позволяют использовать персонализацию – можно добавить ФИО клиента, адрес, номер заказа и пр. Такие SMS возможно отправлять исключительно с использованием имени отправителя. Перед отправкой текст шаблона должен быть обязательно согласован у операторов, абонентам которых он будет отправляться.

Документация по API-методам в Сообществе: [SMS API](https://docs.exolve.ru/docs/ru/api-reference/sms-api/)↗

Описание
========

Категоризация
-------------

Шаблонные SMS разделяются на следующие категории:

**Авторизационные SMS.** Содержат код/пароль/OTP для авторизации, аутентификации и идентификации. Например:

* Учётные данные пользователя для входа в сервис с указанием его названия
* Информирование об изменении телефона, кот. используется для идентификации
* Код подтверждения операции (ещё НЕ произошла)

**Сервисные SMS.** Уведомления об операциях по предоставлению услуг. Например:

* Приветственное сообщение по факту регистрации в услуге (кроме бонусной или программы лояльности)
* Статус оказания услуги, подтверждение заказа, статус доставки, возврата, обмена
* Напоминания о запланированном событии — например, о назначенном визите
* Технические работы, остановка, возобновление работы сервисов
* Информирование о событиях, влияющих на условия оказания услуг (повышение АП)
* Информирование об изменении платёжных реквизитов, адреса, контактных данных
* Уведомление о входе/попытке входа/выходе в систему самообслуживания
* Информирование о расписаниях занятий, итоговых достижениях, домашнем задании

**Транзакционные SMS.** Информирование о проведение фин.операции в данных момент или о невозможности совершения этой операции. Должен быть ЯВНО указан тип операции, номер счёта, сумма. Например:

* Состоявшаяся операция зачисления/списания/снятия/резерва ДС
* Выплата комиссии, начисление % по вкладу, конвертация ДС в другую валюту
* Отмена/невозможность совершения этих операций

Рекламный трафик не шаблонируется. Шаблонные сообщения не могут содержать призывы к покупке, информацию о бонусной или программе лояльности.

Тарификация
-----------

Шаблоны как сущности создаются и согласуются бесплатно. Оплачиваются отправленные SMS в соответствии с [тарифами](https://exolve.ru/tariffs/). Стоят значительно дешевле, чем рекламные/информационные.

Как создать шаблон
------------------

Чтобы отправлять шаблонные SMS нужно:

1. Подписать договора как ЮЛ/ИП
2. Отправить заявку на согласование альфа-имени
3. Дождаться согласования альфа-имени
4. Заполнить заявку на регистрацию шаблона и отправить её на согласование операторам (см.ниже)
5. Дождаться согласования шаблонов у операторов

После согласования шаблонов операторами можно отправлять SMS с таким текстом по сниженной цене от альфа-имени, для которого шаблон создавался. При отправке SMS сверяется текст шаблона и текст сообщения. Если совпадают, SMS тарифицируется в соотвествии с категорией оператора. Если не совпадают, такое SMS не будет отправлено.

### **Заявка на регистрацию шаблона (ссылка на бизнес-процесс))**

Заявку можно отправить в интерфейсе ЛК или по API, применив метод [CreateTemplate](https://docs.exolve.ru/docs/ru/api-reference/sms-api/creating-template/).

**1. Ввести внутреннее название.**

С помощью этого названия легче и быстрее найти шаблон в списке шаблонов. Видно только пользователю Exolve.

**2. Выбрать альфа-имя**

Шаблон создаётся, согласуется и используется для имени отправителя из этого же приложения. У одного имени может быть неограниченное кол-во шаблонов. Шаблон можно создать только для согласованного имени.

**3. Выбрать категории и операторов**

Пользователь выбирает категорию для шаблона и операторов, абонентам которых планируется отправлять SMS с таким текстом. В большинстве случаев шаблон принадлежит одной категории, но возможна ситуация, когда потребуется выбрать 2-ую категорию, т.к. у каждого оператора своя категоризация шаблонов.

|  | Авторизационный | Сервисный | Транзакционный |
| --- | --- | --- | --- |
| МТС | ✔️ | ✔️ | ✔️ |
| МегаФон | ✔️ | ✔️ (=информационный) | ✔️ |
| Билайн | ❌ | ✔️ | ✔️ |
| Tele2 | ❌ | ✔️ (=идентификационный) | ✔️ |
| Ростелеком | ❌ | ✔️ | ✔️ |

**4. Ввести текст шаблона и пример SMS**

Пользователь вводит текст шаблона, используя переменные, и пример текста SMS для этого шаблона. Шаблон должен без затруднений соотноситься  текстом сообщения. В примере можно использовать любые реальные значения («Уважаемый Иван», «Ваш код: 1234»). Недопустимо использовать исключительно переменные значения. Шаблон не обязательно должен содержать переменные значения. Корректность шаблона и соответствие текста шаблону ― ответственность пользователя.

Пример авторизационного SMS:

* Шаблон: Ваш код для входа: %d.
Не сообщайте никому!
* Пример SMS: Ваш код для входа: 12345.
Не сообщайте никому!

Пример сервисного SMS:

* Шаблон: Заказ: %w{1,3} на сумму %d руб. Доставит курьер %w. Ожидаемое время доставки: %w{1,2} с %d до %d
* Пример SMS: Заказ 101849 на сумму 5500 руб. Доставит курьер Олег. Дата доставки: 12 мая с 15:00 до 20:00

Пример транзакционного SMS:

* Шаблон: VISA %d: %d %d покупка на сумму %d руб. %w{1,5} выполнена успешно. Доступно: %d руб.
* Пример SMS: VISA 1234 : 20.06.23 14:11:27 покупка на сумму 800.00 руб. RESTORAN MOSKVA выполнена
успешно. Доступно: 1500.00 руб.

**5. Отправить заявку**

МТС Exolve не задействован в процессе непосредственного согласования, отправляет заявку на рассмотрение выбранным пользователем операторам. Отправлять SMS с таким текстом возможно только после одобрения этих операторов.

Детали шаблона
--------------

Список шаблонов с деталями доступны в приложении в разделе «Каналы» → «SMS» → «Шаблоны». В карточке шаблона отражены статусы операторов и история согласования, текст шаблона и пример SMS из заявки. Информацию по созданным шаблонам можно также получить по API, применив метод [GetTemplates](https://docs.exolve.ru/docs/ru/api-reference/sms-api/getting-templates/). Детали конкретного шаблона доступны через [GetTemplate](https://docs.exolve.ru/docs/ru/api-reference/sms-api/getting-template/).

### Статусы операторов

У каждого оператора в рамках шаблона есть свой статус:

1. На согласовании. Присваивается после отправки шаблона на согласование. Оператор ещё рассматривает заявку. Отправка шаблонных SMS с таким текстом пока недоступна.
2. Согласовано. Присваивается после согласования у оператора. Доступна отправка SMS с одобренным текстом от имени, для которого шаблон регистрировался.
3. Отклонено. Присваивается, если оператор отклонил шаблон. Пользователю транслируется комментарий с причиной отказа в карточке шаблона в ЛК. Отправка шаблонных SMS с таким текстом недоступна. Нужно создать новый шаблон, учитывая замечания, и отправить его на повторное согласование оператору.

Шаблон можно безвозвратно удалить вручную (to be 2024). При отключении альфа-имени автоматически безвозвратно удаляются все его шаблоны.

Требования к переменным значениям
---------------------------------

В шаблоне можно использовать переменные значения. Вместо них будут подставляться уникальные данные: имя клиента, дата доставки, номер заказа и т. п. До и после переменных важно использовать пробел. Запрещено использовать переменную часть вида %w+

| Переменная | Значение | Для чего можно применить |
| --- | --- | --- |
| %w | Непрерывный набор букв и цифр с или без символов | [задача]-00, Иван |
| %d | Непрерывный набор цифр с или без символов | 20.10.21, 15:00-10:00, 5000 |
| %d+ | Последовательность цифр с или без символов, с пробелами | +7 900 000 00 00 |
| %w{1,n} | Ограниченная последовательность буквы, цифр, символов с пробелами n – количество слов: от 2 до 20 если использовать подряд несколько переменных %w{1,n}, то общее кол-во слов тоже должно быть до 20 Например:  ✔ %w{1,10} %w {1,10} — всего 20 слов  **Х**  %w{1,10} %w{1,11} — тут уже 21 слово | Иван Иванов,  12 мая,  Мега Парнас,  RU\_00 20 |
| %n{1,n} | Ограниченная последовательность чисел с или без символов, с пробелами n – количество чисел: от 2 до 20 |  |

Возможные символы: ! № # % . , : ; ? \ / ( ) + - “ ”― \_ ' " ` & ^ ? { } [ ] < > / \ | ! @ # $ % ^ ( ) + = ~ \*.
