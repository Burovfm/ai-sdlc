# Каскады (Рассылки)

Введение
========

INLINE

**Каскадная рассылка** — последовательная отправка сообщений в несколько каналов (текстовый и/или голосовой) с указанием условий перехода к следующему каналу (как правило, недоставка или сообщение не было прочитано). Алгоритм проверяет, кто из получателей рассылки прочитал/получил сообщение, и эти люди исключаются из каскада. Сообщение сначала отправляется в каналы с наименьшей стоимостью, затем с более высокой. Конечный пользователь гарантированно получает сообщение в один из каналов.  Создание, настройка и отправка рассылки доступны по API и в ЛК.

Доступные каналы отправки SMS:

* Голосовой
* Текстовый

Каскад — ресурс приложения. Каскады создаются бесплатно. Максимальное количество не ограничено.

Документация по API-методам в Сообществе: [Campaign API](https://docs.exolve.ru/docs/ru/api-reference/campaign-api/)↗

Описание
--------

### Перед отправкой рассылки

Перед отправкой каскадной рассылки нужно:

* Подписать договор как ЮЛ/ИП для отправки каскада в текстовый и голосовой каналы (для ФЛ доступны только звонки)
* Купить мобильный или городской номер для исходящих вызовов
* Согласовать альфа-имя для отправки SMS
* Загрузить файл с записанным аудиосообщением и создать на его основе ресурс голосового SMS

### Создание и настройка каскадной рассылки

**1.** Ввести внутреннее название каскадной рассылки. Должно быть уникально в рамках приложения.

**2.** Настроить шаги. Каскад может состоять из 2 или более шагов. Максимум — 10.

**2.1.** Выбрать для каждого шага канал — звонок или SMS — и условия перехода на следующий шаг.

2.1.2. Для канала «Звонок» выбрать один из ресурсов голосового SMS этого приложения. Условием перехода на следующий шаг может быть:

* Если этот звонок не принят
* Если звонок принят
* В любом случае

2.2.2. Для канала «SMS» выбрать согласованное (активное) альфа-имя этого приложения и ввести текст SMS (одинаковое для всех получателей). Условием перехода на следующий шаг может быть:

* Если это SMS не доставлено
* Если это SMS отправлено или доставлено
* В любом случае

**2.2.** Выбрать номер для исходящего звонка. Если в добавлено несколько голосовых шагов, в них всех будет использоваться этот номер для дозвона.

**2.3.** Настроить расписание отправки. По умолчанию рассылка отправится с понедельника по пятницу с 09:00 до 18:00. Можно выбрать другие дни и интервалы. Для каждого дня можно добавить до 4 не пересекающихся интервала. Если за указанный интервал платформа не успеет уведомить всех получателей, отправка рассылки автоматически приостанавливается и возобновляется в следующий указанный интервал.

Можно отправить рассылку без учёта местного времени (по МСК) или с учётом часового пояса абонента (см.п.3).

**3.** Загрузить список получателей рассылки в CSV. Можно скачать и заполнить шаблон — в нём нужно указать номер телефона в формате 79999999999 (допустимо начать номер с +7 или 8) и часовой пояс в формате UTC+2. Если активирована опция «Учитывать часовой пояс абонента» из п.2.3, платформа МТС Exolve отправит рассылку по указанным в файле часовым поясам.

Если номера и зона указаны в корректном формате, на экране отразится количество добавленных в рассылку номеров.

Если номера и/или зона указаны в некорректном формате, на экране отразится ссылка на скачивание отчёта с ошибками. Нужно исправить значения и загрузить корректный файл.

**4.** Проверить настройки рассылки перед её запуском. Рассылка отправится в текущий интервал (если попадает по времени) или в следующий указанный.
