# Регистрация / вход через МТС ID

Описание
========

Основной способ регистрации и входа в Личный кабинет МТС Exolve — связка email + постоянный пароль. Также доступен альтернативный способ создания аккаунта и входа в него с помощью МТС ID. Процессы в этом случае идентичны. Нужно:

1. Ввести номер телефона любого оператора
2. В зависимости от настроек в [МТС Профиле](https://profile.mts.ru/account/safety/auth-level) ↗ далее один из вариантов ниже:
   * Нужно ввести одноразовый пароль — будет отправлен в SMS на введённый номер
   * Нужно ввести одноразовый пароль из SMS + постоянный пароль, установленный в [МТС Профиле](https://profile.mts.ru/account/safety/auth-level) ↗
   * Нужно ввести постоянный пароль, установленный в МТС Профиле

Регистрация и вход через МТС ID бесплатны, возможны с номером любого оператора. Способ входа можно настроить в [МТС Профиле](https://profile.mts.ru/account/safety/auth-level) ↗. Если у клиента не создан аккаунт в МТС Профиле, он создастся автоматически при регистрации в МТС Exolve через МТС ID.
