Ограничение 60 мин на изменение номера без ввода SMS
----------------------------------------------------

Пользователь ввёл номер телефона, кликнул "Подтвердить", но не ввёл код из SMS. Тем не менее, номер установлен, в целях безопасности его можно изменить через 60 мин.

Подтверждение номер и, соответственно, это ограничение доступно только для потенциальных и активных пользователей. Для пользователей в фин/адм блоке опция заблокирована.

-------------------------------

| По клику на «Удалить» появляется модальное окно с подтверждением удаления и перечислением услуг, на работу которых повлияет удаление подтверждённого номера |  |
| При наведении на кнопку «Удалить» показывает тултип |
