# Маскировка номера (Инкогнито)

Введение
========

INLINE

Маскировка номера (внутреннее наименование услуги – Инкогнито)  —  функционал, позволяющий сохранять анонимность реального номера телефона конечного пользователя, подменяя его на альтернативный, т.е. оставаться инкогнито. В результате пользователям гарантировано абсолютную конфиденциальность и безопасность личных данных.

В МТС Exolve инкогнито может быть реализовано посредством настройки переадресации вызова на номер = безусловной переадресации.

Описание
========

Настройка переадресации
-----------------------

Настройка переадресации на номер может быть произведена:

* через карточку номера в ЛК Р
* с помощью API (см. описание: setCallForwarding (wiki Exolve), [setCallForwarding](https://docs.exolve.ru/docs/ru/api-reference/numbering-api/call-forwarding/) (Сообщество))

Отключение переадресации
------------------------

Отключение переадресации (удаление настроек) также может быть произведено:

* через карточку номера в ЛК Р
* с помощью API (см. описание: deleteCallForwarding (wiki Exolve), [deleteCallForwarding](https://docs.exolve.ru/docs/ru/api-reference/numbering-api/deleting-call-forwarding/) (Сообщество))
