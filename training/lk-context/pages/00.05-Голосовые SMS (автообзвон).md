# Голосовые SMS (автообзвон)

Описание
========

INLINE

Голосовое SMS — эффективный способ проинформировать клиентов с помощью предзаписанного аудиосообщения или синтезированной речи без привлечения менеджера.

Используется, чтобы:

* Оповестить клиента о статусе заказа, доставки или бронирования
* Рассказать о специальном предложении
* Напомнить о записи к врачу
* Пригласить на мероприятие
* Проинформировать об отмене или задержке рейса
* Уведомить о состоянии баланса

Документация по API-методам в Сообществе: [Voice API](https://docs.exolve.ru/docs/ru/api-reference/voice-api/)↗

Возможности автообзвона
-----------------------

Запустить автоматизированную голосовую рассылку можно двумя способами:

**1. С аудиофайлом из библиотеки приложения:**
1.1. Студийная запись — загрузить заранее записанное аудио в библиотеку приложения
1.2. Синтезированная речь — синтезировать речь и добавить аудио в библиотеку приложения
*Преимущества*: не нужно при каждом звонке генерировать аудио, можно переиспользовать файл из библиотеки.
*Недостатки*: нужно сначала создать ресурс голосового SMS в ЛК или по API, привязать к нему это аудио, и только потом запустить обзвон через [MakeVoiceMessage](https://docs.exolve.ru/docs/ru/api-reference/voice-api/making-voice-message/), указав ID этого голосового SMS.

**2. Онлайн-синтез:**
Передать текст для синтеза прямо при звонке — речь будет сгенерирована на лету по заданным параметрам. *Преимущества*:

* Не нужно заранее создавать аудиофайл и ресурс голосового сообщения. Достаточно указать в API-методе [MakeVoiceMessage](https://docs.exolve.ru/docs/ru/api-reference/voice-api/making-voice-message/#tts) текст и настройки для синтеза речи.
* Возможна персонализация.

*Недостатки*: нужно передавать текст и настройки синтеза при каждом звонке.

Как запустить автообзвон
------------------------

Создать ресурс голосового SMS можно в Личном кабинете или по API с помощью метода [Create](https://docs.exolve.ru/docs/ru/api-reference/voice-api/creating-voice-message/).

Предварительно:

1. Купитеь мобильный или городской номер, с которого будет осуществляться обзвон
2. Добавить аудиофайл в библиотеку приложения — можно загрузить студийную запись или синтезировать речь

Создание голосового SMS:

Голосовое SMS — это ресурс для автообзвона, преднастроенный шаблон. Создаётся бесплатно.

1. Ввести название ресурса голосового SMS — оно нужно, чтобы быстро найти нужный ресурс в списке. Конечный потребитель его не увидит.
2. Привязать аудиофайл — выберите нужный из аудиобиблиотеки приложения
3. Настроить перевод на оператора (опционально) — конечный потребитель может соединиться с оператором для консультации по нажатию на определённую клавишу

Запуск автообвзона:

1. Вызвать API-метод [MakeVoiceMessage](https://docs.exolve.ru/docs/ru/api-reference/voice-api/making-voice-message/), указав во входных параметрах или идентификатор ранее созданного голосового сообщения, или текст для синтеза речи на лету. Тарифицируется как исходящий звонок. Для синтеза речи взимается дополнительная плата.

Получение статистики:

1. Посмотреть историю звонков с деталями и актуальными статусами можно в разделе «Статистика» Личного кабинета или с помощью API-метода [GetList](https://docs.exolve.ru/docs/ru/api-reference/statistics-api/call-history/).

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

В тестовом периоде можно создать неограниченное количество ресурсов голосового SMS, но позвонить можно только на свой подтверждённый номер. После подписания договора это ограничение снимается.
