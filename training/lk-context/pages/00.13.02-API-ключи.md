# API-ключи

При создании приложения автоматически генерируется авторизационный API-ключ, который даёт доступ к использованию телеком функционала

* API-ключ по умолчанию имеет доступ ко всем API МТС Exolve
* Создать новый (дополнительный) API-ключ нельзя (на этапе MVP)
* По умолчанию ключ скрыт, раскрыть можно по клику на иконку глаза
* Удалить API-ключ нельзя (на этапе MVP)
