# Онлайн-уведомления о событиях

Введение
========

Пользователь получает уведомления в режиме онлайн о состоянии услуг (ход звонков, статус сообщений и т.п.). URL-адрес для получения таких уведомлений (event URL) устанавливается в настройках приложения и привязывается к услуге. Таким образом, добавив URL для услуги callback, пользователь получает на него уведомления по всем созданным в этом приложении обратным звонкам.

Описание
========

Точки входа
-----------

1. Пользователь переходит в карточку приложения → “Настройки” → блок "Уведомления о событиях” → добавляет URL-адрес и выбирает услугу

Услуги
------

1 URL = 1 услуга. Максимальное количество URL — 5 (по количеству услуг):

* Callback
* Голосовые SMS
* Переадресация входящих вызовов на номер / SIP ID
* Переадресация входящих вызовов на URL
* Текстовые SMS

**Подробнее про уведомления при входящем звонке**

Отправка уведомлений на URL о ходе звонка при входящих реализуется следующим образом:

Сначала платформа проверяет, указан ли URL для отправки уведомлений на номере (в структуре переадресации, пользователь мог сделать это через использование метода SetCallForwarding, заполнив event\_URL). Затем - есть ли в приложении

1. Если URL указан и на номере, и в приложении, то ивенты будут отправлены на URL из номера
2. Если URL указан и на номере, но пуст в приложении, то ивенты будут отправлены на URL из номера
3. Если URL не указан на номере, но указан в приложении, то ивенты будут отправлены на URL из приложения

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Потенциальный и активный пользователи могут добавлять и удалять URL-адресы для уведомлений
* Заблокированный и замороженный пользователи не могут добавлять, удалять и редактировать URL-адресы, уведомления фактически не присылаются
