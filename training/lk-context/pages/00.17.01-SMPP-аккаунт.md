Введение
========

INLINE

SMPP (Short message peer-to-peer protocol) — протокол, позволяющий ускорить отправку SMS за счёт работы в режиме постоянного подключения

Пользователь создаёт SMPP-аккаунт, чтобы получить учётные данные (логин и пароль), которые будет использовать для отправки SMS по протоколу SMPP.

SMPP-аккаунт — ресурс приложения. Создание и использование SMPP-аккаунтов бесплатное

Документация по API-методам в Сообществе: [SMS SMPP](https://docs.exolve.ru/docs/ru/api-reference/sms-smpp/)↗

Описание
========

Из чего состоит раздел:

1. Список всех созданных SMPP-аккаунтов с датой создания, внутренним названием, логином и паролем

Создание SMPP-аккаунта
----------------------

При создании SMPP-аккаунта указывается его внутреннее название, чтобы его можно было быстрее найти в списке всех SMPP-аккаунтов. Автоматически генерируются логин и пароль. Пользователь может создать SMPP-аккаунт:

1. На странице “Обзор” приложения кликает на “+SMPP-аккаунт” в блоке быстрого добавления → открывается модальное окно создания нового SMPP-аккаунта
2. На странице “Обзор” приложения кликает на “+Создать SMPP-аккаунт” в блоке "Сообщения" → открывается модальное окно создания нового SMPP-аккаунта
3. В карточке приложения переходит во вкладку Сообщения → “SMPP-аккаунты” → кликает “Создать SMPP-аккаунт” на странице со списком всех SMPP-аккаунтов → открывается модальное окно создания нового SMPP-аккаунта

Удаление SMPP-аккаунта
----------------------

Пользователь может удалить SMPP-аккаунт:

1. В списке SMPP-аккаунтов:
   1. При наведении на SMPP-аккаунт показывается иконка мусорки → подтверждает удаление в модальном окне
   2. Отмечает галочками SMPP-аккаунты на удаление → подтверждает удаление в модальном окне

Ограничения в зависимости от статуса по ЖЦ
------------------------------------------

* Потенциальному пользователю недоступно создание SMPP-аккаунтов
* Активный пользователь может создать неограниченное количество SMPP-аккаунтов, а также удалить их
* Заблокированный и замороженный пользователи могут просмотреть уже созданные SMPP-аккаунты, но не могут ни удалить их, ни создать новый
