# Имена отправителей SMS

|  |  |  |  |
| --- | --- | --- | --- |

Введение
========

INLINE

**Имя отправителя** (ранее — альфа-имя) –  буквенно-цифровая подпись, от которой конечному абоненту приходит SMS. В отличие от мобильных номеров гарантирует почти 100% доставляемость SMS, повышает доверие у клиентов.

Имя могут зарегистрировать только активные ЮЛ/ИП, оно должно отражать название компании или домен. Обязательно согласовывать у операторов. До согласования отправлять SMS с такого имени нельзя. 1-ого числа каждого месяца взимается АП за каждого согласовавшего оператора. Если оператор отклонил имя, можно исправить заявку в соответствии с комментариями и отправить на повторное согласование.

Имя – ресурс приложения.

Интеграция канала SMS с сайтом, приложением или ПО заказчика возможна по HTTP API или SMPP.

Документация по API-методам в Сообществе: [SMS API](https://docs.exolve.ru/docs/ru/api-reference/sms-api/)↗

Список имён отправителей и карточка имени
-----------------------------------------

В приложении есть раздел "Каналы", подраздел "SMS" и вкладка "Имена отправителей".

1. При переходе на вкладку "Имена отправителей" отображается список всех имен отправителей для данного приложения. В списке отражены все имена приложения. Пагинация появляется, если количество имен в списке больше 11 строк.
2. В списке имен отображаются следующие поля:

   * ID с возможностью скопировать.
   * Кликабельное название, ведущее в карточку имени в текущей вкладке.
   * Общий статус имени (Активно / Неактивно / Отключено).
   * Статусы операторов для данного имени (На согласовании / Отклонено / Отключено).
   * Суммарная АП (Абонентская плата) за всех операторов для данного имени.
   * Дата активации имени, если она есть.
3. Во вкладке доступно общее количество имен. Если ни одного имени не добавлено, доступна иллюстрация. Пагинация появляется если в списке имен больше 11 строк. Доступна ссылка с инструкцией, открывается в модальном окне
4. Добавить новое имя отправителя может только активный пользователь. Кнопки "Добавить" и "Отключить" заблокированы для пользователей в фин/адм блоке

Детали имени:

1. Переход в карточки имени осуществляется в текущей вкладке по клику на имя в списке всех имён в разделе "Каналы" → "SMS" → "Имена отправителей"
2. В каждой карточке доступно:

   * Имя отправителя
   * Общий статус имени («Неактивно» / «Активно» / «Отключено»)
   * ID с возможностью скопировать
   * Дата активации (если есть)
   * Список добавленных операторов с статусами, индикатором возможности отправки SMS и АП
   * История согласования
   * Памятка со сроками согласования, открывается в модальном окне
   * Иконка с тремя точками для отключения имени
3. Дата активации = дата согласования имени 1-м оператором. Указан прочерк, если имя не согласовано ни одним оператором
4. У каждого оператора доступен бейдж с актуальным статусом:
5. Индикатор возможности отправки SMS и текст в тултипе при наведении зависят от статуса:
6. У отклонившего оператора доступна ссылка «Что делать». По клику на ссылку «Что делать» открывается модальное окно с текстовой инструкцией. В инструкции описаны возможные дальнейшие действия: отключение этого имени и создание нового для всех нужных операторов или создание нового имени, отличного от отклоненного, для отклонившего оператора.
7. В Истории согласования перечислены все изменения статусов по всем операторам и имени в целом с указанием даты и времени. По умолчанию История скрыта. Открывается по клику на ссылку. Если в Истории >11 строк, доступна пагинация
8. В каждой записи со статусом «Отклонено» доступен текстовый комментарий, передаваемый из заявки в CRM

Регистрация имени отправителя
-----------------------------

1. Перейти в приложение → "Каналы" → "SMS" → вкладка "Имена отправителей"
   * Раздел доступен для ЮЛ/ИП в любом статусе
   * Для ФЛ вкладка "Имена отправителей" отсутствует
   * Потенциальный пользователь видит заглушку с иллюстрацией
2. Кликнуть кнопку “Добавить имя отправителя”
   * Кнопка активна только для активного ЮЛ/ИП. Для ЮЛ/ИП в фин.блоке / админ.блоке кнопка заблокирована
   * Ограничения на кол-во имён в аккаунте или в приложении нет
   * Переходит на страницу добавления нового имени в текущей вкладке. Доступна форма регистрации:
     + Поле «Имя отправителя»
     + Множественный выбор операторов
     + Поле «Кол-во SMS на 1 оператора»
     + Зона загрузки подтверждающих документов
     + Инструкции, открываются в модальных окнах
3. Ввести имя в поле “Имя отправителя”
   * Обязательно. Минимум — 3, максимум — 11 символов. Регистрозависимы
   * Только латиница (строчные и/или прописные буквы) или латиница с цифрами
   * Нельзя использовать только цифры
   * Разрешены спецсимволы "!", "?", "-", "\_", ".", "(", ")"
   * Нельзя использовать только специальные символы
4. Выбрать операторов
   * Список операторов с множественным выбором:
     + МТС
     + Билайн
     + МегаФон
     + Сматрс, Мотив
     + Теle2
     + Ростелеком
   * По мере выбора/удаления операторов обновляется сводка с названиями, АП каждого оператора и суммой АП
   * Доступна памятка, открывается в модальном окне
5. Ввести примерное кол-во сообщений в месяц в "Кол-во SMS на 1 оператора"
   * Обязательное поле, строго числовое
   * Минимум – 1, максимум – 10 цифр. Доступен счетчик
   * Доступен тултип
6. Загрузить скан подтверждающего документа
   * Обязательно. Максимум: 4 файла. Форматы: PDF, JPEG, JPG, PNG. Макс. размер каждого файла: 5 Мб
   * Доступна памятка, открывается в модальном окне
7. Кликнуть "Отправить на согласование"

В результате отправки имени отправителя на согласование возможны 2 сценария.

**Позитивный сценарий:**

* Создан ресурс имени в системе Exolve
* Отправлена заявка в CRM, прикреплена к договору КА. Для каждого оператора создаётся отдельная заявка (т.е. на одно альфа-имя может быть до 6 заявок)
* Отправлен email с заявкой на регистрацию имени в сторону Omni
* Имя добавлено в список имён приложения со статусом "Неактивно". Все операторы получают статус "На согласовании". В Истории согласования имени указаны добавленные операторы и название(-я) прикреплённых документов
* Действие записывается в Журнале действий с указанием имени и названия приложения
* Имя ещё неактивно, отправка SMS с него недоступна, АП спишется только после согласования

**Негативный сценарий:** Заявка не отправлена, имя не создано. Ошибка, если:

* такое имя уже существует в аккаунте в любом статусе кроме "Отключено"
* имя не удовлетворяет требованиям (базовая проверка на символы)
* не загружен файл подтверждающего документа: "Загрузите подтверждающий документ"
* не тот формат файла: "Загрузите файл в формате PDF, JPG, JPEG, PNG"
* файл более 5 Мб: "Загрузите файл меньшего размера. Максимум — 5 Мб"
* не выбран ни один оператор: "Выберите хотя бы 1 оператора"
* не введен ожидаемый трафик: "Введите кол-во SMS"

После отправки заявки на регистрацию альфа-имени на группу рассылки [anames@exolve.ru](mailto:anames@exolve.ru) от почты [omni\_a2p@mts.ru](mailto:omni_a2p@mts.ru) будет приходить письмо со статусом заявки:

1. Если пришел статус «Согласовано», то Сотруднику ДКС-ОЭО нужно найти в CRM соответствующую заявку и перевести в статус «Согласовано»
2. Если пришел статус «Отклонено», то Сотруднику ДКС-ОЭО нужно найти в CRM соответствующую заявку и перевести в статус «Отклонено» и написать комментарий из письма (причину отклонения)

Отключение имени отправителя
----------------------------

Фактическое удаление имени не предусмотрено, т.к. важно сохранить историю согласований. Терминальный статус — отключение. После отключения оператор получает статус "Отключено", отправка SMS в сторону его абонентом недоступна, АП за него больше не взимается. Реактивировать такого оператора нельзя.
Можно отключить имя, только если все его операторы в статусе "Согласовано" или "Отклонено".

Операторов необходимо уведомить об отключении до 20 числа текущего отчётного периода, чтобы они успели отключиться в этом месяце. Поэтому отключение возможно только с 1 по 20 число месяца включительно. С 21 до последнего дня месяца отключение блокируется.

**Порядок отключения:**

1. Пользователь успешно переходит в карточку имени
2. Пользователь кликает на иконку с тремя точками и выбирает опцию "Отключить". Отключение недоступно (кнопка отсутствует), если в имени есть хотя бы 1 оператор в статусе "На согласовании" или статус имени "Отключено"
3. Модальное окно с выбором даты отключения открывается, и пользователь выбирает "Сейчас" в качестве даты отключения, затем нажимает "Отключить"
4. Модальное окно закрывается, и появляется тост с уведомлением "Имя отключено". Нет перехода на другую страницу

В результате отключения:

1. Статус имени изменяется в системе Exolve на "Отключено"
2. Ресурс имени успешно удаляется в системе Onyma
3. Трафик через имя блокируется, отправка SMS недоступна
4. Все открытые заявки имени автоматически закрываются в CRM
5. Отправляется уведомление об отключении имени в сторону Omni
6. Статус имени у всех операторов изменяется на "Отключено" в системе Личного кабинета (ЛК) в списке имен, в карточке имени и в Истории согласования в карточке имени, с указанием даты и времени. Имя переносится в подраздел «Архив»
7. Отключение имени логируется в Журнале действий: «Имя отправителя {имя} отключено в приложении {название приложения}». «Исполнитель: «Пользователь». Тип: «Имя отправителя»
8. Omni получает уведомление с запросом на отключение имени и отправляет запрос операторам
9. После отключения имени на стороне операторов Omni изменяет статус имени и отправляет уведомление со статусом "Отключено" в сторону Exolve
10. Имя успешно отключено в текущем отчётном периоде
11. Не взимается АП с баланса клиента за первое число следующего месяца
12. ДС (ежедневная стоимость) за оставшиеся дни текущего месяца не возвращаются на баланс клиента

Блокировка альфа-имени при блокировке аккаунта
----------------------------------------------

При административной блокировке имя отправителя отключится автоматически:

* через 30 дней, если блокировка произошла до 25 числа месяца
* 25 числа следующего месяца, если блокировка произошла после 25 числа месяца

При финансовой блокировке:

* при блокировке 1 числа месяца и наличии активации АИ в текущем месяце (1 числа), для всех АИ проставляем дату отключения 25 числа следующего месяца.
* при блокировке 1 числа месяца и отсутствию активации АИ в текущем месяце, отключаем 25 числа текущего.
* при блокировке в середине месяца (не 1 число) для всех АИ ставим дату отключения 25 следующего месяца.

архив

При фин/адм блокировке альфа-имя всё ещё закреплено за клиентом следующие 3 отчётных периода. Имя отключается автоматически 1-го числа 4-го отчётного периода нахождения в блокировке. При этом заявка на отключение формируется 20-го числа 3-го отчётного периода. Даже если юзер выйдет из блокировки 20-го или позже, имя всё равно отключится.

Долг клиента не суммируется — при выходе из блокировки с его баланса автоматически взимается АП только за текущий месяц.

Кейсы:

1. Юзер попал в фин.блок 1 сент. Пополнил баланс на нужную сумму 15 ноя — списана АП в полном размере только за ноябрь. При этом МТТ платит операторам за все 3 месяца (сент, окт, ноя).

2. Юзер попал в фин.блок 1 сент. Если аккаунт так и не разблокирован, 20 ноя (3-й отчётный период) автоматически сформирована заявка на отключение. 1 дек имя отключено.

3. Юзер попал в адм.блок 30 сент. Если аккаунт так и не разблокирован, 20 ноя (3-й отчётный период)​ автоматически сформирована заявка на отключение. 1 дек имя отключено.

----------------------------------------------------
